# Motion Pipeline — 动画运动质量度量与数据扩增

一套**动画运动质量度量体系**：检测脚部滑动、从数据标定质量阈值、并能
自证度量的准确性。在它之上接了一个应用——带质量门禁的动画数据扩增
（镜像 + 变速），为 UE Motion Matching 供给数据。

> 与姊妹项目 [`maya_to_ue`](../maya_to_ue/) 的关系：
>
> | | maya_to_ue | motion_pipeline（本项目） |
> |---|---|---|
> | 回答的问题 | 文件**能不能**进引擎 | 动画**好不好**、值不值得用 |
> | 判定方式 | 规则式校验（28 项布尔检查） | 度量式质检（连续指标 + 统计标定阈值） |
> | 类比 | lint | 评审 |
>
> 两者在管线上串联：先过合规检查，再过质量门禁。

---

## 核心能力

### 1. 运动质量度量（`mp_core.foot_contact`）

- **脚部接触检测**：支撑相识别、接触事件计数、按骨骼角色分组
  （踝 / 掌 / 脚尖——脚尖支撑相滚动是正常的，实测其"滑动"读数是踝的
  3 倍，混在一起统计会毁掉阈值）
- **滑动度量**：区分 root motion 与原地动画（原地动画支撑脚匀速后扫
  是正常的，度量的是「偏离匀速的程度」）
- **冻结帧裁剪**：自动识别并裁掉动画首尾的静止段（实测某文件 273 帧
  只有 36 帧有动画，不裁则指标虚高 12 倍）

### 2. 阈值标定与度量自验证（`mp_core.baseline` / `synth`）

阈值不拍脑袋：

1. 扫描已知好的片段 → 得到指标分布 → p95 作为候选阈值
2. **注入已知量的合成劣化**作为「已知坏」批次 → 验证阈值真能分离好坏
3. 度量本身也要自证：注入量 `a` 应产生 `2a` 的读数——实测线性区间
   **响应斜率 = 1.00**

### 3. 带门禁的数据扩增（`mp_core.augment` / `gate` + `mp_maya.augment`）

- **镜像**：全骨架左右反射（`S·M·S` 世界矩阵变换），逐骨骼验证过
  指标精确互换；骨架不可镜像时整体拒绝，不产出半对的结果
- **变速**：±15% 显式重采样烘焙（不用 `scaleKey`——它把关键帧落到
  非整数位置却沿用原切线，实测滑动 +199%）
- **质量门禁**：每条变体与**它自己的源**对比，恶化超过容差（默认
  +25%）即拒收——生成比源更差的数据是负收益，门禁是扩增能安全存在
  的前提

## 快速开始

需要 Maya 2022+（用 `mayapy`）。所有度量逻辑纯 Python、无 Maya 依赖，
119 个单测可在任何 Python 3.7+ 下运行。

```bat
:: 单测
mayapy -m unittest discover -s tests

:: 基线扫描（文件或整个目录）
mayapy launch_baseline_scan.py --fps 30 corpus\source

:: 标定：扫描 + 注入劣化 + 阈值建议
mayapy launch_baseline_scan.py --fps 30 --calibrate corpus\source

:: 扩增：每条源 × {1.00, 0.85, 1.15} × {原样, 镜像}，过门禁才导出
mayapy launch_baseline_scan.py --fps 30 --augment --out corpus\augmented corpus\source

:: 一键可视化报告（展示用）：扫描 + 标定 + 全部图表 → 单个 HTML
mayapy launch_baseline_scan.py --fps 30 --report out\quality_report.html corpus\source
```

`--report` 产出**自包含 HTML**（SVG 内嵌、零依赖、无 JS）——双击打开、
邮件直发、贴进作品集页面都不变形。内含：

- 每条动画的**体检图**：脚部高度轨迹 + 接触段绿带 + 滑动红条，
  一眼看出哪条动画哪几帧有问题
- **度量自验证表**：注入已知劣化 vs 实测响应（斜率 1.00 = 度量可信）
- **好/坏分布图**：每个指标的标定证据 + 阈值线
- 全量测量数据表

Maya GUI 内使用见 `launch_baseline_scan.py` 文件头注释。

## 结构

```
mp_core/            纯 Python 核心（无 Maya/UE 依赖，全部可单测）
├── foot_contact.py   接触检测与滑动度量
├── baseline.py       分布统计与阈值标定
├── synth.py          合成劣化注入（度量自验证）
├── augment.py        扩增的决策层（镜像映射、重定时数学）
├── gate.py           质量门禁（绝对阈值 + 相对源）
└── viz.py            SVG 图表与自包含 HTML 报告
mp_maya/            Maya 适配层（懒加载 cmds）
├── pose_sampler.py   逐帧世界坐标采样、骨骼角色分类、帧率对齐
└── augment.py        镜像/重定时的落地执行、FBX 导出
launch_baseline_scan.py   入口（CLI + Maya GUI 两用）
tests/              119 个单测
tools/              诊断脚本（对照实验）
docs/               设计文档（含全部实测记录与被推翻的假设）
corpus/             语料目录（source/ 放源，augmented/ 放产物）
```

## 实测揪出的坑（每条都有数据）

| # | 坑 | 后果 | 修法 |
|---|---|---|---|
| 1 | hip sway 被路径长度判成 root motion | 滑动虚高 **40 倍** | 改净位移判定 |
| 2 | 动画尾部冻结帧被计入统计 | 指标虚高 **12 倍** | `moving_window` 自动裁剪 |
| 3 | 脚尖与踝混在一个分布 | 阈值被脚尖带偏（**3 倍**差异） | 骨骼角色分类 |
| 4 | Maya 帧率不匹配只警告不重采样 | 每秒指标偏 **25%** | 导入前对齐时间单位 |
| 5 | `scaleKey` 重定时沿用原切线 | 滑动 **+199%** | 显式重采样烘焙 |
| 6 | 先镜像再变速（分数采样重打的曲线） | 滑动 **2 倍** | 顺序规则：先变速后镜像 |

> 这张表是本项目方法论的缩影：**每个功能都在真实数据上验证，
> 每个被推翻的假设都留在文档里。**
