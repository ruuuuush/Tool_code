# curve-thinning

## Purpose

导出前按档抽稀动画曲线的冗余关键帧：误差有界、可撤销、留痕。

逐帧烘焙的动画（每帧一个 key）让 FBX 体积虚胖、曲线编辑器无法手调。FBX 插件内部完成 bake，场景中不存在可处理的"导出副本"，因此抽稀作用于场景曲线——这决定了它必须默认关闭、显式可选、一次撤销可整体恢复，与"不做破坏性自动修复"的定调相容。

## Requirements

### Requirement: 误差有界的关键帧抽稀算法

系统 SHALL 提供纯函数式抽稀算法：输入等距或非等距的 (时间, 值) 序列与容差，输出保留的 key 索引。被删除的 key 在保留 key 的线性插值下取值偏差 MUST 不超过容差。首尾 key MUST 始终保留。

#### Scenario: 直线段被抽干
- **WHEN** 输入一条严格线性的序列与任意正容差
- **THEN** 只保留首尾两个 key

#### Scenario: 误差不超过容差
- **WHEN** 输入任意序列与容差 ε，删除索引集合为算法输出
- **THEN** 每个被删 key 处的线性插值值与原值的偏差 ≤ ε

#### Scenario: 端点保留
- **WHEN** 输入任意至少两个 key 的序列
- **THEN** 输出包含第一个与最后一个索引

#### Scenario: 全平序列零误差
- **WHEN** 输入值全部相等的序列
- **THEN** 只保留首尾两个 key，且不引入任何误差

### Requirement: 抽稀档位映射到分类容差

系统 SHALL 提供「关闭/低/中/高」四档，非关闭档映射到按通道类型区分的容差：平移（厘米）、旋转（度）、缩放（比率）。档位越高容差越大、删得越多。

#### Scenario: 档位容差单调
- **WHEN** 比较低、中、高三档的同一通道类型容差
- **THEN** 低 < 中 < 高

#### Scenario: 关闭档不执行
- **WHEN** 档位为「关闭」
- **THEN** 导出流程不调用抽稀，曲线不发生任何变化

### Requirement: 场景执行必须可撤销且只动连续数值曲线

抽稀 SHALL 在导出前作用于骨架层级的动画曲线，全部删除操作 MUST 包在一个 undo chunk 中，用户一次撤销即可完整恢复。非连续数值曲线（stepped 切线、布尔/枚举）MUST NOT 被修改。

#### Scenario: 一次撤销恢复
- **WHEN** 抽稀删除了若干 key 后用户执行一次撤销
- **THEN** 全部被删 key 恢复

#### Scenario: stepped 通道被跳过
- **WHEN** 某条曲线含 stepped 出切线或为 animCurveTL 类型
- **THEN** 该曲线的 key 一个不少

#### Scenario: 统计产出
- **WHEN** 抽稀执行完成
- **THEN** 产出档位、触及曲线数、前后 key 总数、最大误差，以及减量最多的若干通道的降采样折线数据
