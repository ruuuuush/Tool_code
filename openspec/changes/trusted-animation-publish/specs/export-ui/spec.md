## ADDED Requirements

### Requirement: 正式发布入口和状态明确
UI SHALL 提供显式正式发布选项及项目、资产、版本输入。调试导出保持既有行为；正式发布 SHALL 使用严格规则并显示真实发布路径。正式推送完成后 MUST 读取独立回执，缺失或失败回执不得显示引擎验收成功。

#### Scenario: 正式发布身份
- **WHEN** 用户启用正式发布
- **THEN** 可以输入项目、资产和版本，首次导模型不可用于该模式

#### Scenario: 缺少回执
- **WHEN** 命令发送成功但正式回执缺失
- **THEN** UI 表示未取得验收结论，保留手动检查入口
