## Context

用户确认采用快速通道并精修现有深色主题，不更换三步向导。Python 3.7 / PySide2 是本机可验证的 Maya 2022 环境；基线 412 项 unittest 通过。现有 UI 公开信号、片段模型和交付卡片行为已有大量测试约束。

## Goals / Non-Goals

**Goals:**
- 保留中性深色背景与蓝色主动作，改善字体、视觉层级、控件反馈及信息密度。
- 默认 1040×760 下三页完整可用；交付结果展开时允许滚动但不隐藏导航。
- 导出时重新验证实时场景，同时沿用用户已经确认的跳过选择。
- 用离屏渲染和回归测试验证结构、交互和实际绘制。

**Non-Goals:**
- 不增加侧边栏、多主题、第三方 UI 库、图标字体或联网依赖。
- 不更改 Maya 场景、骨架、动画算法、FBX 参数及 UE 导入策略。
- 不拆分整个主窗口模块或增加通用抽象层。

## Decisions

1. **应用字体限于工具窗口。** 使用本机已安装的中文无衬线字体，提供系统字体回退；代码区域单独用等宽字体，不修改 Maya 的 QApplication 样式。替代方案是全局应用 Fusion，拒绝，因为会影响宿主 Maya。
2. **控件图形用现有 Qt 能力绘制。** 勾选标记和下拉箭头用 QPainter / QIcon 保证可见；复用现有 delegate 模式，避免外部图标资源与样式表多字体语法导致的回退。
3. **保留内容 API，只优化排列。** 导出表单用本地/UE 两组、中文重名策略显示并保留原始配置值；详情用转义后的富文本标题和段落；检查结果提供文本状态，颜色只作辅助。
4. **压缩交付结果，不删除证据。** 合理限制代码预览高度，缩短产物行，保留折叠、复制、推送、失败原因和曲线证据。底部导航独立于可滚动内容。
5. **修补跳过集合传递，不缓存验证结果。** ExportRequest 新增 `skipped_checks` 默认独立空集合，UI 在导出时传入 `skipped_ids()`；导出器继续实时 build_context，再用该集合运行检查并生成摘要。
6. **修正过时的步骤提示。** 文案直接引用区域名称而不是易变的圈号，保留枚举性步骤编号。

## Risks / Trade-offs

- 字体可用性因机器不同而变 → 检查已安装字体并回退至系统字体，截图验证中文可读。
- Qt5 / Qt6 枚举与绘制差异 → 使用仓库已有兼容写法，至少在 PySide2 实际运行测试与离屏绘制。
- 富文本可能误解释节点名或错误消息 → 所有动态文本用标准库 html.escape 后插入。
- 交付卡片缩短可能丢失操作入口 → 保留原有按钮与失败展开行为，补结构回归测试。
- 跳过允许放行错误项 → 保留现有导出前确认和 manifest/report 留痕，不弱化未跳过错误的阻断。

## Migration Plan

无需迁移配置或 manifest。通过现有启动器 reload_and_show 载入新代码；回滚只需还原本次源代码变更。

## Open Questions

无待用户决策项。真实 Maya/UE 会话的视觉确认仍需用户本机打开工具；不能用离屏渲染冒充宿主端到端验证。
