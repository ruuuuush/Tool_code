## 使用与验证

- 当前工具版本统一为 0.3.0。tool_deployment.py 的 CLI：build <源码目录> <zip路径>；install <zip路径> <缓存目录>；pin <缓存目录> <版本> <锁文件>；verify <缓存目录> <锁文件>。
- 输出包和锁文件的父目录需预先创建。安装按版本独立缓存，不覆盖旧版本。项目锁文件必须由可信项目配置管理，哈希不是签名。
- 回滚使用 pin 指向已有旧版本；随后重启宿主。只切工具版本，不回滚场景或引擎资产。
- Maya 脚本入口：将独立 bootstrap 所在目录加入 sys.path，import tool_deployment，调用 launch_maya(cache, lock)。UE 调用 launch_unreal(cache, lock, manifest_path)。项目锁文件不含本机绝对缓存路径，缓存由机器启动配置指定。
- 已完成 470 项 unittest、compileall、OpenSpec strict 和 diff 校验；新增 15 项部署测试，包含独立 Python 进程加载已安装缓存版本。
- 未自动修改 userSetup、工具架或 UE 工程；未验证两台机器或真实 Maya/UE 部署。兼容性为最低版本声明，不是宿主认证。
