## ADDED Requirements

### Requirement: 每个区域只有一个标题

界面上任一内容区 MUST 只呈现一个标题。步骤容器、分组框、面板内部标题 MUST NOT 对同一内容重复命名。

#### Scenario: 片段区不重复命名
- **WHEN** 用户打开动画片段那一步
- **THEN** 界面上「动画片段」这个名字只出现一次

#### Scenario: 导出区不重复命名
- **WHEN** 用户打开导出那一步
- **THEN** 界面上「导出」这个标题只出现一次

#### Scenario: 面板自身不带标题
- **WHEN** 检查面板、片段面板、导出面板被放进步骤容器
- **THEN** 面板内部不再渲染自己的标题标签

### Requirement: 界面不承载说明文字

界面 MUST NOT 显示解释操作意图的引导语（如「告诉工具每段动画的帧范围」）。必要的说明 MUST 由控件自身的 placeholder、状态文案或悬浮提示承担。

#### Scenario: 步骤区无说明副标题
- **WHEN** 任一步骤显示
- **THEN** 步骤标题下方没有说明性副标题文字

#### Scenario: 输入控件自带示例
- **WHEN** 用户看到需要填写的输入框
- **THEN** 该输入框的 placeholder 给出格式示例

### Requirement: 三步向导式导航

工具 SHALL 把工作流拆成检查、片段、导出三步，同一时间只展示一步。顶部步骤条 MUST 标出每步的状态（已完成 / 当前 / 未开始），用户 MUST 能通过步骤条或底部按钮切换。

#### Scenario: 初始停在第一步
- **WHEN** 工具窗口打开
- **THEN** 显示检查这一步，步骤条把第一步标为当前

#### Scenario: 点击步骤条跳转
- **WHEN** 用户点击步骤条上的第三步
- **THEN** 内容区切换到导出，步骤条把第三步标为当前

#### Scenario: 底部按钮前进后退
- **WHEN** 用户在第二步点「下一步」
- **THEN** 内容区切换到第三步

#### Scenario: 首尾步骤的按钮状态
- **WHEN** 当前在第一步
- **THEN** 「上一步」不可用
- **AND** 当前在最后一步时，「下一步」不可用

#### Scenario: 一屏装得下
- **WHEN** 窗口以默认尺寸打开
- **THEN** 当前步骤的内容不需要整页滚动即可看全

### Requirement: 检查结果作为导出门禁并可见

存在 Error 级未通过项时，导出动作 MUST 保持禁用，且界面 MUST 说明卡在哪一步、还差什么。

#### Scenario: 检查未跑时不能导出
- **WHEN** 用户还没运行过检查就切到导出步
- **THEN** 导出按钮不可用，并提示需要先完成检查

#### Scenario: 有 Error 时不能导出
- **WHEN** 检查结果含 Error 级未通过项
- **THEN** 导出按钮不可用，并显示阻断项的数量

#### Scenario: 只有 Warning 时可以导出
- **WHEN** 检查结果只含 Warning 与 Info
- **THEN** 导出按钮可用

#### Scenario: 步骤条反映检查状态
- **WHEN** 检查跑完且无 Error
- **THEN** 步骤条把第一步标为已完成
